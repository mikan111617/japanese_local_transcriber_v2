# まず最初に

ZIPを右クリックして **「すべて展開」** してください。
ZIPの中から直接バッチファイルを実行しないでください。

展開後、最初は **`START_HERE.bat`** をダブルクリックしてください。
このファイルは、エラーが起きてもコマンド画面が消えないようにしてあります。

セットアップが完了したら、以後は **`run.bat`** で起動できます。

# 日本語ローカル文字起こし

Windowsで音声・動画ファイルをローカル文字起こしするためのGUIツールです。

## 特徴

- 日本語を明示的に指定して文字起こし
- 高精度 `Whisper large-v3` を初期設定
- 日本語特化 `Kotoba Whisper v2.0` も選択可能
- 高速な `large-v3-turbo` も選択可能
- MP3 / WAV / M4A / FLAC / OGG / AAC / WMA / OPUS / MP4 / MOV / MKV / WEBM に対応
- 無音区間除外（VAD）
- 固有名詞・専門用語を「認識ヒント」として入力可能
- 複数ファイルをまとめて処理可能
- TXT / タイムスタンプTXT / SRT / VTT / JSON を同時出力
- NVIDIA GPUが使えれば自動利用し、失敗した場合はCPUへフォールバック
- システムへのFFmpegインストールは不要

## 最初の使い方

### 1. Pythonを入れる

Python 3.10～3.12 を推奨します。

Pythonをインストールするときは、可能なら
`Add Python to PATH`
にチェックを入れてください。

### 2. install.bat を実行

フォルダ内の

`install.bat`

をダブルクリックします。

必要なライブラリが `.venv` にインストールされます。

### 3. run.bat を実行

`run.bat`

をダブルクリックするとGUIが起動します。

### 4. 音声を選択して「文字起こし開始」

初回だけAIモデルを自動ダウンロードします。
ダウンロードしたモデルは `models` フォルダに保存されます。

2回目以降は、そのモデルをローカルから読み込みます。

## モデルの選び方

### 高精度：Whisper large-v3

迷ったらこれです。
精度最優先の初期設定です。

ただし、CPUだけだとかなり時間がかかる場合があります。

### 日本語特化・高速：Kotoba Whisper v2.0

日本語音声向けに学習されたモデルです。
large-v3より軽く、日本語では比較候補としてかなり有力です。

会話・日本語番組に近い音声では特に試す価値があります。

### 高速：Whisper large-v3-turbo

large-v3よりかなり速い一方で、精度は少し落ちる可能性があります。

### 軽量：Whisper medium

PCスペックが厳しい場合の選択肢です。

## 認識ヒント

人名、作品名、専門用語、ゲーム名など、
Whisperが間違えそうな単語を入れてください。

例：

`舞黒館の惨劇、真歩流、愛理、零度警部、ファイアーエムブレム、生成AI`

固有名詞の誤認識を減らす助けになります。

## 出力

指定したフォルダに次のファイルを保存します。

- `音声名.txt`
- `音声名_timestamps.txt`
- `音声名.srt`
- `音声名.vtt`
- `音声名.json`

TXTはBOM付きUTF-8なので、Windowsの各種アプリでも文字化けしにくい形式です。

## GPUについて

NVIDIA GPUを自動検出します。

現在のfaster-whisper / CTranslate2でGPUを使う場合、
CUDA 12系のcuBLASとcuDNN 9が必要です。

GPU側の環境が合わない場合、このアプリはCPUへ自動的に切り替えます。

CPU時は `int8`、GPU時は `float16` を使います。

## 完全オフラインについて

「文字起こし処理」自体はローカルです。

ただし初回はモデルを取得するためインターネット接続が必要です。
一度 `models` フォルダへモデルを取得した後は、同じモデルなら再ダウンロードされません。

外部APIへ音声をアップロードする処理はありません。

## 精度をさらに上げるコツ

1. まず `Whisper large-v3`
2. Beam は `5`
3. VAD はON
4. 固有名詞を認識ヒントへ入れる
5. 同じ音声をKotoba Whisperでも試して比較する

音声によって、large-v3とKotoba Whisperのどちらが強いかは変わります。

## v2: CUDA DLL不足への対応

`Library cublas64_12.dll is not found or cannot be loaded`
のようなエラーが出るPCでは、NVIDIA GPUは見えていても
CUDA 12 / cuDNN 9 の実行ライブラリが不足しています。

v2ではこの状態を起動前に確認し、GPUが使えなければCPUへ自動切り替えします。
また、文字起こし開始後にCUDA関連エラーが出た場合もCPUで自動再試行します。

CUDAを別途導入しなくてもCPUモードで利用できます。
